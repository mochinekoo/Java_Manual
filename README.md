# マップ
* 一対一のデータを格納できるもの
* 例：　aa : 11 、　ii : 22、　uu ： 33
```java
Map<String, Integer> map = new HashMap<>();
map.put("aa", 11);
map.put("ii", 22);
map.put("uu", 33);
```

# リスト
* データを格納できるもの。
* 例： [a, i, u]
```java
List<String> list = new ArrayList<String>();
list.add("a");
list.add("i");
list.add("u");
```
